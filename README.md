# Food Delivery Time Prediction

## Project Overview
This project uses machine learning to predict food delivery time in minutes.

## Dataset
The dataset is located at `Dataset/Food_Delivery_Time_Dataset.csv`.

## Python Code
`Python_Code/project.py` performs data cleaning, exploratory data analysis, feature encoding, model training, and evaluation.

Models used:
- Linear Regression
- Ridge Regression

## Reports
- `Reports/EDA_Report.html` — Exploratory Data Analysis report
- `Reports/Project_Report.pdf` — Project report

## Libraries
- pandas
- numpy
- matplotlib
- seaborn
- sweetviz
- scikit-learn

## Run the Project
Run this command from the project root:

```bash
python Python_Code/project.py
```
